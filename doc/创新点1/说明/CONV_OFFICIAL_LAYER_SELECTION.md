# 官方权重的重新选层：先校准筛查，再匹配训练

日期：2026-10-15。用户授权执行。旧8/10/12是固定设计，不是此前选出的最优三层；旧分层诊断基于RU权重，不可直接搬到官方BoQ。本轮不修改专利稿、旧代码、检查点或封存结果。

## 数据和边界

复用GSV固定地点计划：2048个查询地点，每地点3个查询视图、1个参考视图，加8192个干扰参考，共6144查询、10240图库、16384张实际图像。训练地点池与该计划地点不重叠。前1024查询地点（3072查询）是校准分区，后1024地点是评估分区。地点分区先于本轮分数固定，但此前项目已使用这些分区，因此这是探索性筛查，不是新盲测。

完全使用官方冻结DINOv2-B/14+BoQ，在全部GSV图库中重新计算官方top20；不同地点25米内的候选排除，保留同地点参考。原RU只提供历史计划、固定照片/视图及训练日程的身份记录，不提供本轮描述子、分层分数或教师目标。

筛查不读取MSLS/Pitts图像、GT或评测分数来选择层；程序仅沿用固定实验合同的元文件哈希。GSV保持原PIL bicubic280→float→ImageNet归一化，匹配旧GSV视图；后续公共验证继续使用原官方float tensor bicubic280/322管线，和E3对照相同，不混淆上轮统一uint8输入的原因核查。

## 无训练筛查

1. 层号一基，固定候选为4/6/8/10/11/12。一次backbone前向可收集所有层的raw post-block patch；L12必须精确重现原模型输出。不把中间层直接塞进只对L12训练过的BoQ。
2. 使用原生20×20、400个patch，不平均池化为10×10，不引入随机投影。patch单位归一化后暂存FP16，打分前重新归一化为FP32。互为最近邻匹配的平均余弦作图片对分数，至少3对匹配才有效；它是伪对应，不是几何GT。
3. 每个查询仅比较官方top20，不能修复top20之外的错误，报告可达错误数。推理打分、候选排序不使用正样本标签。
4. L12为锚层，从其余五层选择两层，共固定10种组合。为了避免各层相似度尺度不同，每层对同一查询的20个候选转为百分位排名，再对三层等权平均；缺有效匹配的候选排除，全部无效则保留官方第一名，分数并列也保留原候选顺序。
5. 分别报告各单层和组合的正确数、相对官方纠错/退化、独立纠错地点、可达错误，以及单层正样本减最强负样本的平均间隔、有效匹配覆盖。组合排名只是**选层代理指标**，不是学习后的卷积融合结果，更不能用其胜负证明训练后一定改善。

## 固定选择规则

只给选择函数传入GSV校准分区，禁止传评估分区。相对于8/10/12代理组合，候选必须同时满足：

- 能纠正官方错误的独立地点至少3个；
- 至少1个纠错地点是8/10/12未纠正的新地点；
- 校准总体正确数不少于8/10/12代理组合。

符合者按“纠错地点数、相对官方净增、新增纠错地点数、较小层号组合”固定顺序选择。注意这里不要求原生局部重排整体胜过完整官方全局检索；它只提出有互补依据的待训练组合。若无符合者，标记`NO_CALIBRATION_SUPPORTED_ALTERNATIVE`，保留原组合并停止新增训练，不硬选一个。

完成校准即写入带校准/候选哈希的`selection.json`，然后才计算和汇总GSV评估分区。评估结果不更改选层，不反向改变门槛，也不挑下一名重新试。
