### 同一真实训练批次的只读梯度诊断

不更新任何参数或优化器；使用三组共同的最后64图像训练批次，读取各组最终检查点。冻结RU的MultiSimilarity损失0.1244469732，跨层组0.1244136095。

跨层组主检索损失在共享颈部上的未裁剪梯度范数0.000522741；**已乘0.1权重**的辅助损失对应范数0.114855133，约220倍。辅助头并不通过最终升维层，辅助损失对该层梯度为0。这提示优化信号可能被辅助目标主导，不证明辅助监督一定有害，也不等同于验证集结果。其他两组表现相似。

残差实际约0.1%，上限是10%；没有观察到上限饱和，但0.1系数仍影响梯度，不能因此说它完全无关。当前先不改变它，以免同时改变多个因素。

## 预先固定的下一轮

问题：此前无收益来自跨层信息本身无帮助，还是辅助训练目标/权重干扰了主检索学习？

| 新组名 | 输入 | 辅助权重 | 排序权重 |
|---|---|---:|---:|
| last_noaux | L12/L12/L12 | 0 | 0 |
| hierarchy_noaux | L8/L10/L12 | 0 | 0 |
| last_lowaux | L12/L12/L12 | 0.001 | 0 |
| hierarchy_lowaux | L8/L10/L12 | 0.001 | 0 |

低辅助权重来自上述**训练梯度**诊断，不由MSLS/Pitts召回率搜索。两辅助头在所有组都计算，保持图结构、参数初始化、参数量一致，仅其损失乘数不同。权重0且weight_decay=0的辅助头必须保持原值；所有优化器参数时钟均512。

- 四组全部重新从RU初始化；不接128步模型，不使用旧训练权重。
- 模型结构、原生20×20网格、10%特征残差上限、FP32、AdamW lr1e-4/wd0/clip1、微批4不变。
- 复用完整8192地点训练缓存和旧硬负样本索引。每步8个均匀抽取的锚地点及其硬负地点，每地点4图，最多64图。512步用4096个步长2的锚地点；不根据验证错误选择训练地点。
- 先四组各8步机械smoke，使用正式日程的前8批，以确保关闭辅助后的主损失确实能训练；不是旧48查询smoke来源。smoke不做性能筛选，四组再各自全新开始512步。
- 每64步记录同批次主梯度及加权辅助梯度，记录RU同批主损失、实际残差、SSM梯度。辅助为0不是直接跳过主分支训练。
- 固定末步完整GSV6144查询/10240图库、MSLS740/18871、Pitts7608/10000成对评测。GSV继续原PIL预处理；标准集继续匹配RU历史的张量bicubic预处理。冻结RU正确数必须复现6030、675、7160。
- 报告两个辅助条件下的跨层对仅L12、两个深度条件下的低辅助对无辅助，以及二者交互差值。记录纠错/退化查询，不只比较总体Recall。
- 不用其中最好的验证轮次、不扫权重、不因先跑一组无收益就停止公平四组对照。仅机械/完整性/基线错误中止。

这是已暴露验证集上的单seed探索筛查，**不是稳定收益确认、独立最终验证或论文原方法逐项复现**。即使出现几个纠错，也需要更长预算和多seed确认；若无净收益，依据实际梯度、残差与难例变化决定是否停止，而不是立即再换损失。
