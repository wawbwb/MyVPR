Local在有效步的K/V输出投影梯度范数均值约0.000972/0.003596。Value并未持续保持早期的微弱梯度；不能用“Value路径没有学到”解释最终失败。

设计中仅设置0.1残差系数，没有对学习后的U输出施加真实幅值上限或保持约束。可学习权重能补偿固定缩放，所以0.1不意味着最多改变10%，更不保证检索排序不变。零初始化只保护起点。这是本方案的明确限制。

数据说明有效聚合映射发生了较大变化，尚不能证明“大扰动”就是唯一因果因素，也不能保证加入约束即可恢复收益。此前通道矩保持/排序保护实验未获得净收益，不能将约束再次包装成已知答案。

## 6. 决策与论文边界

本轮不支持“局部—全局K/V协同能在创新点1上形成第二创新点”的效果主张；当前完整候选在三套R@1均下降，Pitts还低于全部训练对照。普通KV适配也下降，因此没有证据仅靠更换聚合器适配位置即可解决问题。

停止当前版本，保留创新点1。不得因发现训练漂移而回头选择较早验证checkpoint，亦不扫描缩放、损失或低秩rank追逐开发集涨点。若未来专门研究扰动约束，需要独立、匹配的预注册实验来隔离幅值与结构效应；本轮没有启动此类追加实验。

两篇ReID参考论文提供可测试的设计启示，但并不保证在冻结DINO、固定GSV训练和VPR跨域检索条件下有效。未证明其原方法错误，也未证明本模块具有论文新颖性。
