# SLGD v2：大图库、固定参考视角与困难查询诊断

## 本轮目的

先确认局部教师在有足够错误与竞争候选的条件下，是否具有可供学生学习的新增判别信息。原 v1 教师、训练结果、门槛不改；不因原来的门控上限错误重新宣称通过。

本轮复用 `logs/slgd_v1/teacher_pilot/last.pt` 的固定最后一步教师，既不重新训练教师，也不启动学生、全量训练或 CLIP。这是学生实验前的独立诊断，不是新网络效果的结论。

## 新协议：在看 v2 分数前固定

- 排除原教师参与训练的全部 8192 个地点。
- 查询地点 2048 个：原教师 1024 个留出地点作为 calibration；再由稳定地点 ID hash 选择 1024 个新留出地点作为 evaluation。GSV 已被多次探索，两部分均不称最终独立测试。
- 每地点 deterministic 采样 4 张图：第 4 张固定为唯一参考，第 1–3 张为查询。**不再用 RU 从三个正样本中挑最容易的正样本。** 总计 6144 查询。
- 再选 8192 个不属于训练地点、查询地点的干扰地点，每地点仅取一个固定视角进图库。总计 10240 参考图、16384 次图像编码。
- 相同地点 ID 是唯一正标签。异地点但距查询小于 25 米的图不参与该查询的候选竞争，以减少近邻地点假负标签；相同地点的固定参考始终保留。GPS 是诊断协议中的排除依据，不是部署输入，因此**本轮不是标准 MSLS/Pitts 指标，也不能对外称一般检索性能**。
- 冻结 RU 给出 top20 候选与候选间隔；困难查询定义为 RU top1 错误，或 top1–top2 分差 ≤0.02。困难样本划分不读局部教师、raw DINO 的分数，也不只挑教师能纠正的样本。
- 以完全相同候选、原生 10×10 池化网格和互为最近邻平均余弦分数，对比 raw DINO 与训练后 projector；匹配数至少 3 才有效，同分沿用 RU 候选顺序，无有效匹配时退回 RU。
- 全部与困难子集都记录正确数、纠错、退化、候选可达与不可达错误，避免把没有进入 top20 的正样本归咎于局部网络。

## 分开判断“样本不足”和“教师没收益”

calibration / evaluation **各自**必须满足：

1. 至少 128 个困难查询。
2. 至少 20 个不同地点存在 RU 错误且正样本在 top20 内。一个地点的三个查询不能算三个独立地点。
3. raw DINO 在困难子集上距离 top20 oracle 至少还有 1 pp 可提升空间。

不满足时结果是 `INSUFFICIENT_HARD_CASES`，表示本轮证据不足，不判定算法失败。不继续堆训练轮数或扫描参数。

只有样本充足，才判断两部分上的教师效果：相对于 raw DINO，困难子集净增至少 5 个正确查询、增幅至少 1 pp、全体查询不净退化、困难候选有效比例至少 95%。通过为 `PASS`，否则为 `NO_TEACHER_ADVANTAGE`。这里的 1 pp 是新协议的 **top20 局部重排 R@1 差**，不是 v1 的二分类准确率；两种指标不能混用。

`PASS` 仍只是探索性教师互补性，不是学生已经有效、语义已有效、稳定收益或新颖性证明。下一步才根据这些候选与困难地点设计匹配的学生 A/B。

## 成本与产物

只缓存原 RU 向量、100 个单位归一化 raw/teacher tokens 与坐标，不保存完整分辨率 DINO 特征。预计 **3.49 GiB**，不是之前 185 GiB 的方案；不额外生成一份拼接特征磁盘缓存。

- RU descriptor 存 FP32；raw / teacher tokens 同样存 FP16；局部匹配转换回 FP32 计算。不宣称与未量化 FP32 位级复现。
- 每 16 个地点保存一个原子 shard，带 hash、形状、dtype、有限性、单位范数检查。中断后 `--resume` 复用通过检查的 shard；损坏或缺少 hash 的 shard 保留到当前缓存的 `quarantine/` 后单独重算，不删除结果或权重。
- 训练机先跑原 17 项模型测试与新增协议测试，再跑 16 个查询地点 / 32 个干扰地点的 smoke，通过后才运行完整诊断。
- 使用现有 VPR 环境与物理 GPU1，不安装依赖。共享 GPU 实验锁占用时退出。
- 推理/诊断代码同步采用 LF 文件；上传后直接检查 CR 字节与 launcher 内容，**不再用引发截字问题的 sed 命令**。
