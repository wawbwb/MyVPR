# 训练跨视角可靠性监督与中心化尺度分配

2026-10-26；新有限实验，旧结果与源码不改。用户授权：尝试补强门控的独立优势，继续实验。

## 假设与边界

旧门控的Pitts整体收益可重复，但主要来自两尺度信息和全局高尺度偏好。原六维单图统计加MS损失未产生足够组间分配。新假设：训练中用同地点不同视角的判别可靠性监督这六维统计，可以让单图门控学到更有效的组间分配；若单图统计不能预测该目标，本轮也可能失败。

全程复用冻结创新点1的322/518 FP32完整描述子缓存，不提取新特征，不加载编码器，不修改创新点1，不使用语义、验证集监督、人工标注。32组是最终FC代数组，不解释为空间区域。仍为12288维和两次编码的推理成本。

## 冻结起点与模型

固定三个配对重复43、44、45（不是三个新盲测种子）；各自以旧重复实验该种子训练集平均门控向量的标量均值b为冻结起点。b只来自32768张训练图像，旧评测不参与b选择。新头均从零输出开始，128参数MLP6→16→1，初值和训练顺序同种子内严格相同。

q=tanh(MLP(单图每组原六维尺度统计))；中心化分配r=(q−mean_group(q))/2；g=b+rho*r，其中rho=min(0.35,0.5−abs(b))，所以g仍在[-0.5,0.5]、每图组均值严格保持b。z=normalize(low+high+g*(high−low))。零输出精确等于冻结标量融合。中心化只约束混合系数均值，不保证归一化后贡献、能量或距离不变。

## 只在训练使用的可靠性教师

每批16地点、每地点4图。每图的正支持是另外三张同地点图的逐组单位向量均值，明确排除自身。负例先用固定等权融合全向量选批内最相似的异地点图，排除GPS距离<25m；两个尺度、所有组使用同一个负例，避免各分支自己选较容易负例。每组各尺度margin为单位组向量与正支持的内积减与负例的内积；目标t=tanh((margin_high−margin_low)/0.1)。它是训练代理目标，不是验证GT或真实可靠性概率。

教师目标不接梯度。损失为原GPS安全MS损失+0.1*MSE(q,t)。推理不需要正例、负例、标签或GPS。主张范围仅为新监督能否支持门控分配，不是把教师或尺度融合宣称为全新概念。

## 匹配训练及反事实对照

所有训练臂固定1024步、AdamW lr0.001、wd0、梯度裁剪1、FP32、同128参数、相同b/rho和样本：

- quality_group：候选，逐组统计、中心化分配、MS+教师MSE。
- quality_static：固定六维正余弦组编码，中心化分配；其余损失相同，检验静态组权重是否已足够。
- quality_shuffled：输入统计相同，但按每图内容摘要打乱q的组对应后再算MSE和融合；检验对应关系。
- quality_global：每图统计先跨组平均，输出同一q；使用同一逐组原始教师MSE。为使全局变化能够训练，此臂直接r=q、不中心化，检验进一步全局比例调整；该明确的映射差异须保留，不能称为所有计算完全相同。
- ms_group：候选的同架构及中心化映射，只用MS；检验新增教师监督的作用。

另评测候选同一最终权重的推理打乱（保留该图完全相同的门控值集合）与全训练集平均32维门控（评测前校准），旧创新点1/518/等权平均和全部旧门控臂也完整保留。不能用另一个训练头的分布替代同权重打乱对照。
