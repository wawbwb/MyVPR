# 单DINO局部—全局交互：固定检查点诊断

## 目的与边界

对`logs/single_dino_interaction_v1/train/last.pt`的1024步最终检查点进行只读诊断。原单DINO、双编码器及创新点1源码、合同、检查点和评测均不修改。不进行优化器更新，不按诊断结果选择新权重；同权重关闭支路和更换路由只属于敏感性检查，不是重训公平对照。

已有完整评测：单DINO三组在GSV留出、MSLS-val、Pitts30k-val均未超过创新点1；对齐、独立扫描、打乱的Top-1选择全部相同。双编码器同样无匹配交互收益。因此不直接延长训练，先定位机制。

## 诊断设计

1. **层内机制**：提取MSLS候选参考图像中的前64张（按索引排序，非随机样本），比较扫描输出与归一化输入范数；把SSM递归项和直连skip项分解；测量残差中的空间均值能量、关闭扫描后的变化、同权重打乱路由变化，以及tanh是否饱和。
2. **聚合前后**：共享同一次冻结DINO提取，将训练后三组、同权重两种路由、关闭context/exchange/全部scan、仅空间均值残差、去空间均值残差逐一通过原冻结BoQ。报告特征相对变化、描述子L2变化及路由差异与整体适配漂移的比例，不把不同量纲的两种范数简单称为“衰减倍数”。
3. **检索间隔**：64个事后解释性查询包含创新点1的全部45个MSLS错误、全部新增退步，再以seed42补足正确样本。候选参考图像为这64个查询在原四组的Top20并集，加全部GT正样本，共1560张参考图、64张查询图；计算最佳正样本减最佳负样本余弦间隔。原四组必须重现其原完整数据库Top-1。干预组仅有此固定候选并集结果，**不报告为完整数据库召回率**，也不把64个刻意挑选样本的正确率当总体准确率。
4. **监督路径**：选择最后128步中保存主检索损失最高的一步（公开此事后选择），重算同一64图训练批。分别反传主损失、0.1倍辅助损失、0.1倍保持损失到各参数组；不创建优化器、不更新权重。比较初始化与最终权重的同批损失。该批代表有监督信号的解释性个案，不能推广为全部训练批的梯度分布。
5. **完整性**：校验原训练、评测seal和模型hash；诊断前后比对冻结主干、三组融合器、原检查点及创新点1受保护源码；任一重现或完整性检查失败即不封存为成功诊断。

## 实现及执行

- `scripts/diagnose_single_dino_interaction.py`：GPU1固定检查点诊断，使用现有GPU互斥锁和20%显存预算；独立输出`logs/single_dino_diagnosis_v1`。
- `src/single_dino_diagnosis.py`：统计、样本选择、候选并集和正负间隔工具。
- `tests/test_single_dino_diagnosis.py`：测试样本覆盖、GT并集、正确间隔定义、干预恢复、辅助梯度路径。

训练机CPU联合测试48项通过，包含新增7项及已有单DINO24项、双编码器17项；未在本机进行代码测试。只读诊断已于2026-10-21启动，后台PID3582357；日志`.cache/single_dino_diagnosis_v1/driver.log`。无额外权重下载、环境安装或训练。

## 已确认的结构事实

辅助损失读取`context`与`local`在`exchange_scan`之前的GAP描述子。因此其对`exchange_scan`、动态低秩融合、refine和最终output层没有直接梯度；这些下游参数由主检索损失和保持项监督。它仍可通过上游共享表示间接影响最终检索，不能说整个辅助损失“完全无效”。单凭该事实不能确定失败原因，须结合数值诊断。

## 完成结果

2026-10-21完成，实际诊断约101秒。48项CPU测试通过；诊断9项完整性/Top-1重现检查全部通过。五个JSON证据已下载至`doc/single_dino_diagnosis_v1/`，下载后逐文件SHA256与`completed.json`全部匹配。没有新增训练、优化器更新或旧权重改写。

### 1. 交互效应在BoQ之前就很小

在声明的64张参考图上，整体新残差/锚点特征L2平均约1.1323%；其中**空间均值分量能量占93.0111%**。这是“每张图内部，向各patch广播的通道分量占主导”，不能解释为不同图像间完全相同的常数。

关闭exchange扫描，融合后残差只改变原残差的1.2425%；同时关闭context和exchange只改变1.2740%；同权重改为打乱路由只改变0.5252%。这些变化在聚合前已很小，不能把主要原因直接归为BoQ压掉交互。

SSM递归项相对扫描输出L2，context平均1.2725%、exchange平均1.1853%；扫描输出与其归一化输入之比分别0.8246%、1.3167%。说明当前检查点的真正状态递归贡献很弱。注意skip-only分解仍包含因果局部卷积和门控，不是“完全没有任何上下文”。tanh饱和元素比例为0，暂不支持“输出被tanh饱和截断”这个解释。

### 2. 描述子主要变化不是来自路由

1624张候选/查询图上的平均单位描述子L2：

| 比较 | 平均L2 | 相对于整体适配漂移的逐图比例均值 |
| --- | ---: | ---: |
| 对齐交互 vs 创新点1 | 0.0244276 | 100% |
| 同权重独立扫描 vs 对齐 | 0.0001953 | 0.8123% |
| 同权重打乱 vs 对齐 | 0.0001622 | 0.6762% |
| 关闭exchange vs 对齐 | 0.0004018 | 1.6724% |
| 关闭全部scan vs 对齐 | 0.0004069 | 1.6930% |

因此当前模型不是没有变化，而是**大部分适配变化与扫描交互开关或路由无关**。这些敏感性数字不能解释为重新训练时关闭扫描也必然得到同样结果。

### 3. 辅助目标明显更容易优化，终端交互未获得相应直接监督

抽查最后128步中保存主损失最大的第941步训练批（64图，事后解释性选择）：

- 初始/创新点1主损失0.2555096，最终权重主损失0.2549344，仅降低约0.2251%。
- 初始加权辅助损失0.1230517，最终0.0577104，降低约53.1007%。
- 已乘0.1的辅助梯度对local/global投影层范数分别为0.0602336/0.0796352，主损失对应梯度0.0006386/0.0006405，约94.3/124.3倍。
- exchange扫描的辅助梯度为0；主损失梯度约1.8847e-5；保持项梯度约1.7849e-6。
- 全参数主梯度与辅助梯度余弦0.00963，接近正交；与保持项余弦-0.2686。不是“辅助与主任务强烈反向”的证据，也不支持把保持约束判为唯一或已确认的主要瓶颈。

较有依据的解释是：当前监督与梯度配比更强地驱动上游分支GAP表征，弱得多地主动优化最终检索和终端交互。该结论来自结构事实加一个困难批的数值验证，尚不是所有批次或其它训练设置的因果证明。

### 4. 原始错误样本间隔多数向错误方向移动

全部45个原MSLS错误查询中，对齐模型相对创新点1的最佳正/最佳负候选间隔平均变化为-0.0010670（余弦分数单位），9条改善、36条变差；无一被纠正。关闭扫描后仍是9改善/36变差。这不是“朝正确方向走，只是幅度不够”的结果，故不建议直接增大残差权重。

去除每张图残差的空间均值后，该固定64查询候选并集上恢复了原19条正确（纠错0、退步0），而原对齐残差为18条正确（纠错0、退步1）。该观察支持排查主导的空间均值分量，但**尚未做完整数据库干预评测，更不是去均值重训已有效**；31/45原错误间隔仍变差，不能宣称找到收益方案。

## 诊断结论及下一步

当前检查点更接近“以图内空间均值/通道校准为主的残差适配器”，没有学出对最终检索有明显影响的局部—全局交互；上游辅助监督偏强、下游交互缺少直接辅助监督是优先处理的设计错位。BoQ会影响最终表示，但没有证据表明它是本轮首要瓶颈；没有饱和证据，也不支持盲目增大rho或单纯延长训练。

建议下一轮先单独修正**监督路径与梯度配比**：将辅助读出移动到交互后，使终端交互获得直接辅助监督，并约束辅助梯度不过度支配共享投影层；保留原骨干、BoQ、0.025上限和三种路由的配对对照。图内残差去均值作为随后独立因素，不与第一步一起堆入后再声称各自已归因。本次未启动任何新训练。

这是固定检查点的机制诊断，不构成独立测试、新颖性或所有可能失败原因的充分因果证明。
