# 创新点1上的尺度一致性条件融合V1

2026-10-26用户授权继续尺度互补探索。上一轮差分注入3048/693/7277，不胜放大/打乱对照；完整322与518描述子等权平均3051/696/7287，相对创新点1为+2/+1/+11。本轮保留两尺度各自的完整聚合描述子，测试条件混合是否超过该强基线，不继续已失败的特征差分注入。

多分辨率及学习尺度权重已有研究：[MultiRes-NetVLAD](https://arxiv.org/abs/2202.09146)、[FE-Fusion-VPR](https://arxiv.org/abs/2211.12244)。后者是帧/事件体系，不能直接移植其性能结论。本轮不是声称发明尺度注意力或普通加权平均；待检验的候选是固定创新点1输出上、以等权平均为零起点的组一致性条件混合及其独立检索价值，完整论文新颖性审查未完成。

## 保留信息的融合位置

创新点1、DINO、neck、BoQ全部冻结。同图322和518分别完整编码、聚合为两个12288维单位向量l、h。按原BoQ最终FC输出布局重排为384通道×32组。同组索引来自共享权重，不代表已证明的物理地标对应；32组也不是原始64个learnable queries。

每组计算6个输入：log(32×低尺度能量)、log(32×高尺度能量)、组内跨尺度余弦、两尺度能量差/总能量、通道平均绝对差/联合RMS、整图两向量点积。共享MLP为6→16(GELU)→1，无输出bias，最后投影全零，共128个可训练参数。

```
g_j = .5 * tanh(MLP(statistics_j))
z = normalize(l + h + g * (h - l))
```

g广播到每组的384通道。零起点精确使用上一轮的normalize(l+h)，避免从较弱322基线开始后把恢复平均的收益算作创新。每组归一化前的相对尺度比例限制在25%–75%，不丢掉任一路，不投影/新增通道值；该比例约束不是最终描述子漂移上限，也不是排序保持保证。

## 四组同结构与预定干预

|训练组|MLP输入与应用|检验|
|---|---|---|
|static_gate|固定32组的6维sin/cos位置编码|仅固定组偏好是否足够|
|global_gate|各组统计先取图内均值，预测一个整图门控|仅逐图尺度权重是否足够|
|group_gate（候选）|各组真实统计，门控作用于对应组|是否需要逐图逐组对应|
|shuffled_gate|同候选输入，预测门控按图像SHA打乱组位置|内容与输出组对应是否有独立作用|

四组128参数、相同张量初值、相同数据顺序和目标。输入和输出自由度因机制而不同，不声称函数空间完全相等。静态组的固定编码不含身份/图像信息；打乱控制保留每图门控数值分布，不保证最终描述子漂移相等。

训练后、读取本轮验证性能前，对全部32768训练图求候选每组门控均值，形成固定32维train_mean_gate，另行冻结评测。若它解释候选收益，不能把收益归于逐图条件化。它不是另一个拟合模型，不用验证集决定权重。

训练不使用此前分支可靠性分类标签，也不根据Top1分歧筛选/重复少量查询。沿用16地点×4视图的GPS过滤MS损失，直接监督融合描述子，记录实际有效步；这与曾因分歧样本不足而停止的可靠性分类准入不同，但不保证本轮有可泛化的学习信号。
