# 非语义 VPR 研究方向评估

日期：2026-09-14。用户决定停止语义提升路线。本文件评估研究选题，不启动训练，也不把候选思路视为已确认创新或已实现增益。

## 优先级一：候选集合条件下的地点判别

**研究问题：局部匹配证据的价值是否取决于它能否排除当前其他地点，而不只取决于它与一个候选有多相似？**

例如，同一查询的一组窗户在十个候选中都匹配很好，这些匹配未必帮助决定哪处地点正确。普通成对评分可能无法显式区分“共同相似”与“可区分证据”。现有失败案例中的相似街道、重复立面和粗几何伪匹配提供了研究动机，但尚未证明这是主要错误机制。

实现假设：保留 Pair-VPR 的全局检索及配对表示，加入候选集合模块，学习跨候选的公共证据和差异证据，输出每个候选相对其他候选的增量分数。训练使用真实检索得到的困难候选集合与多正样本排序目标。不要直接把最高分、最罕见局部特征或匹配数当真值。

VPR 特有的核心难点是一个地点可能对应很多数据库图片。因此“同一正确地点的多视角支持”不能与“多个不同地点的共同纹理”混淆。可以研究对近重复候选数量不敏感的集合建模及重复候选一致性约束：训练时重复/移除近重复参考图，要求已有物理地点间的判断不因重复票数失真。训练地点标签可用于约束；推理主方法不读取 query GPS 或 GT，也不能假定候选真实地点分组已知。

新颖性边界：Pair-VPR 已有成对学习；SuperGlobal 已利用 top-ranked 图片上下文；VLAD-BuFF 已解决特征重复计数；传统图像检索还有 diffusion、query expansion 等方法。仅增加候选 self-attention、减去均值或做 IDF 不足以成为贡献。潜在贡献必须落在“候选条件的可区分证据 + 多视角冗余鲁棒性”的明确机制和跨库实验上。尚不能声称无人研究。

重要边界：固定候选图像时，独立 pair 评分本来不应因复制另一个候选而变化。重复一致性主要用于防止新增集合模块引入密度偏置，不应伪称已经发现原 Pair-VPR 的重复候选缺陷。原错误中的公共纹理混淆仍需独立诊断。

可实现的接口是 s_i = s_pair(q,d_i) + Δ(q,d_i,{d_j})。Δ基于候选间的配对表示或局部证据差异学习，而非只对已有标量分数做温度缩放。仅比较正负分数的训练损失也不能算新贡献：已有对比学习会比较候选，待检验的区别是推理时的表示本身依赖候选集合。

训练前可行性检查应在独立开发候选中同时包含成功和失败查询，核对：同一查询的错误高分是否反复依赖跨地点共有特征；正确候选是否具有可由现有表示提取的区别；这些区别是否被普通pair评分忽略。若只能看出相似街景、无法提出可计算区别，就不应凭31例oracle直接立项。使用完整配对模型的离线表示缓存做首筛可降低训练成本；作者完整stage-two训练资源需求很高，本项目不默认承担从头复现预算。

最小试验：

1. 在独立开发城市构建固定候选集，先验证完整 Pair-VPR 的候选内排序有效性和剩余错误，不以反复查看的 MSLS 错误训练。
2. 比较原 Pair、同预算独立 pair 微调、普通候选集合 attention、带重复候选一致性的方案。候选数、输入分辨率、参数及训练预算尽量匹配。
3. 增加候选乱序、重复候选、数据库密度改变和远处相似干扰图压力测试；同地点多个正样本共同处理，不能互相当负样本。
4. 如果原表示不包含可利用的差异，冻结小头失败只能停止该小头配置；不要无限换标量分数规则救结果。继续解冻配对模块需要明确的开发集证据。

预期评价：R@1、纠错/退化、候选召回、不同数据库密度下稳定性、平均与P95延迟、缓存大小。需超过原 Pair 和普通集合模型；仅抗重复压力测试提升但真实检索不改善，不足以宣称总体准确率提升。

参考：[Pair-VPR 官方代码](https://github.com/csiro-robotics/Pair-VPR)、[SuperGlobal](https://research.google/pubs/global-features-are-all-you-need-for-image-retrieval-and-reranking/)、[VLAD-BuFF](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/6086_ECCV_2024_paper.php)。

## 优先级二：地点接近与视觉可匹配性的分离监督

**研究问题：如何同时保持跨视角地点不变性，又能区分视觉上极相似的邻近位置？**

地理接近不保证看到相同场景，看到同一立面也不保证相机位置满足地点标签。仅依赖地点ID的统一拉近、或者仅依赖重叠分数的排序，可能产生不同的错误。这是任务定义与监督结构问题，不需要语义类别。

候选方法：训练期分别表达地点关系与可匹配关系。地理标签约束地点身份，具有可核验来源的相机姿态/SfM/深度或匹配证据提供可见重叠监督。困难样本需覆盖近且低重叠、近且高重叠、较远但外观相似等情况。低重叠不能自动改标为不同地点；GPS 边界与不可靠几何目标应表示不确定性而非硬改GT。推理可以保留单张RGB及单描述子。

区别于旧 M3/RU：旧方法监督单个 patch 的可靠性；此方向改变训练图像之间的关系和近邻排序约束。区别于单纯难负采样：要说明相互冲突的地理/可见性监督如何被处理，而不是只把 batch 变难。

新颖性风险较高：[CliqueMining](https://arxiv.org/abs/2407.02422)已研究地理距离敏感性；[SAGE（ICLR2026）](https://proceedings.iclr.cc/paper_files/paper/2026/hash/30b1749bb9769674ddbbcc662f9bfe7f-Abstract-Conference.html)已有在线地理视觉图与困难采样；[VOP（WACV2025）](https://openaccess.thecvf.com/content/WACV2025/html/Wei_Breaking_the_Frame_Visual_Place_Recognition_by_Overlap_Prediction_WACV_2025_paper.html)已有重叠预测。不能把三者组合便称为原创。先验证监督冲突是否实际存在且可被稳定处理，再设计损失。

最小试验：先审计训练集元数据、跨视角关系和可用几何监督，测出冲突样本规模；复现同骨干的普通采样与 CliqueMining/SAGE 相关采样对照。若只有普通难例采样已经解释全部提升，则成果属于有效基线改进，而不是所提分离监督的贡献。

适用性：若论文要求严格单阶段、单描述子，应优先考虑此方向。代价是需要可靠的几何/可见性数据；现有粗 MNN 与仿射计数不够担任监督真值。

## 优先级三：将有效配对排序压缩到单图检索

**研究问题：Pair-VPR 的候选内判别有多少能被不访问参考图的单图描述子表达？哪些关系不能被简单点积表达？**

训练期用有效视觉 pair teacher 对困难候选集合给出相对排序；学生保留单图编码和ANN检索。监督目标应优先是同一候选集合中正负顺序与间隔，不是单个 CLS 或 attention 的逐元素拟合。保留原始检索标签，避免无条件复制 teacher 错误。

它与之前 CLIP 蒸馏的区别是 teacher 在项目内已经表现出地点判别能力。但 +54 来自 Pair 自身global→refined，不能推导 RU 学生也可获得54例纠错，更不能保证单向量能表达双图交互。

普通排序/关系蒸馏已有大量先例，例如[DistilVPR](https://ojs.aaai.org/index.php/AAAI/article/download/28905/29722)和[非对称查询处理](https://ojs.aaai.org/index.php/AAAI/article/download/37487/41449)。潜在研究贡献应围绕：哪些配对关系可由单描述子表达、如何识别并避免无法一致拟合的教师约束，以及在固定描述子维度/时间预算下保留多少教师纠错。仅换 teacher、加KL或LoRA不是充分创新。

最小试验：先在与训练隔离的候选集合上，确认教师优于拟使用的学生，并同时统计教师退化；设置普通检索训练、常规关系蒸馏、所提方法三组。训练阶段的 teacher 优势筛选只使用训练标签，不用测试真值。若教师没有可迁移优势，或蒸馏只能提高拟合度却不提高独立检索，停止。

这个方向更适合追求效率与精度折中，教师预计算可能昂贵，但推理和数据库存储容易控制。

## 备选及明确不优先项

多帧/多视角能够增加观测信息，但会改变当前单图任务和数据需求。若接受这种范围变化，可以研究有限帧预算下非冗余视角选择；必须与同帧数、同延迟基线比较。[UniPR-3D（论文页面标注ECCV2026接受）](https://arxiv.org/abs/2512.21078)已经使用VGGT的2D/3D token及可变长度序列，因此“用VGGT做VPR”本身不是新点，也不宜作为当前单卡项目的第一项。

不优先开展：重新包装动态/静态加权；单纯更换骨干/聚合器；SAM均值+粗几何重排；只扩top-K；只以置信度门控旧分数；只把已有数据混合训练。

尤其置信度和自适应计算已经有直接工作：[To Match or Not to Match](https://arxiv.org/abs/2504.06116)、[Through the Lens of Doubt](https://arxiv.org/abs/2510.13464)、[FoL++](https://arxiv.org/abs/2604.22390)。它们应作为相关基线。拒绝难例提高已接受查询的精度，不等于全部查询R@1提高。跨数据训练也有[QAA官方实现](https://github.com/arplaboratory/QAA)，不能把多数据训练本身作为新贡献。

## 论文证据与执行次序

首选方向一。若必须保持单阶段，改选方向二。不要三条同时实施。

先冻结评估协议：MSLS-val仍可做历史回归，但不再作为独立最终证据。从可用且未参与本项目选模的数据中选开发与测试集合；可考虑Pitts30k、Tokyo24/7、AmsterTime等互补条件，但需核查实际数据可用性、旧实验使用史和预训练地理重叠，不能直接宣称“从未见过”。多帧实验另立协议。维持官方GT，不挑最有利距离门槛。

最小首筛应先确认强基线、足够的有效训练关系和非饱和验证任务，再用一个固定预算比较。此前256地点开发集满分不适合继续选模。明确小预算只能停止当前配置，不能作为理论否定；也不要因未提升就无界追加训练。

通过首筛后至少3个训练种子、两个不同条件的测试集；用逐查询配对统计，存在序列相关时按序列/地点做重采样。记录R@1/R@5、纠错和退化、延迟/存储，报告置信区间。实际方法必须超过匹配基线；oracle仅说明上限。论文贡献需能经消融区分于更大模型、额外训练、更多候选或更多观测。
