# WPPR浅层赢家保留先导实验

仅非语义视觉匹配。冻结官方Pair-VPR全部权重，通过第二decoder block的只读hook
获取CLS，单独LayerNorm后拼接双向CLS1536维；小头1536→128→1预测完整双向分数。
最终教师仍为原12层，不修改官方源码或旧缓存代码。

候选池44；训练512个原GSV train地点，校准128、评估256个原dev地点。
按标签哈希预先选择，不根据GT/纠错/后排赢家挑查询。三个查询集合地点互斥，
原train/dev参考库互斥，但校准和评估共享dev参考库，不能称完全独立场景。
GSV可能属于教师预训练数据；这是适配可行性先导，不是独立泛化验证。

只训练小头20轮，seed42；Huber回归+温度2列表KL；校准winner retention@12
选轮次，平局取最早。评估只在选定后运行。首轮保留浅层预测最高的12候选，
再以这些候选的完整教师分数重排，不混用浅层和深层分数。
预定门槛：评估赢家保留率>=99%，后排21—44赢家>=10且保留率>=90%。
后排不足标记INSUFFICIENT_TAIL_CASES，不事后挑补例、不自动认定通过。

第一轮采集所有44候选的完整教师评分并只保存浅层CLS，不保存dense特征；
64条CPU dense LRU，按查询原子保存+校验，重启可续提取。训练中断从固定seed重训小头。
所有前20教师分数与旧缓存复现校验；使用原图像SHA、严格权重身份和代码契约。
512+128+256=896查询，39424图像对/78848方向前向；CLS约231MiB另加少量评分。
这不是已经实现早退：采集hook不截断前向，不用此阶段耗时声称加速。
理论每方向decoder层数44×2+12×10=208，对照top20=240、top44=528；
图像编码、内存和调度成本不在此式中，实际加速必须后续测量。
