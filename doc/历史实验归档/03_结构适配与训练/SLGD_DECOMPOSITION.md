# SLGD 固定检查点分解诊断

上一轮三组各512步已完成，6144查询：RU 6030、纯检索5929、L12辅助5933、L10辅助5933。三组都有训练更新，两种辅助都实际活跃；L10相对L12校准区−3/评估区+3，总体没有优势。不能把整个下降归因于L10，因为纯检索也退化。

本次不训练、不调权重，保留所有旧文件，仅复用同一初始化和固定最后检查点做诊断。

## 固定比较

- 原始RU全局：重建初始模型的全局支路，必须复现旧RU逐查询正确性。
- 初始混合：重建原来的OT随机初始化和统一projector初始化，参数及探针描述子哈希必须与三组训练前一致。
- 三个训练组的全局支路：同一最终模型，推理时只取全局描述子，量化BoQ变化后的检索表现。
- 三个训练组的完整混合：必须逐查询复现已保存的6144个top1预测，不能仅匹配总体R1。
- 原始RU全局 + 三个训练组各自的局部支路：固定sqrt(.8)/sqrt(.2)替换，辅助隔离全局漂移与融合影响。不是重新训练的公平“冻结全局”对照。

共11个固定推理组合；不挑最优alpha/检查点/层，不运行MNN教师。对相同GSV校准/评估划分及冻结困难标签报告成对纠错/退化、净增、困难净增和全局/局部余弦漂移。

初始混合比RU低，说明初始化融合本身造成损失；训练后全局比RU低，说明全局检索确实漂移，但不代表全部错误均由该支路独立造成；训练后混合比其自身全局低，说明固定20%局部融合在该模型上有负贡献。三者可同时发生，排名变化不能简单做可加因果归因。

仅在训练机GPU1运行，原VPR环境。每张图片只编码一次DINO，四个固定聚合头复用同一冻结特征；descriptor-only缓存约3.5GiB，不缓存native patch。原子分片、SHA256、断点恢复；损坏片保留并报错，不静默覆盖。旧结果不动。
