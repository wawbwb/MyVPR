# 视觉配对自适应预算：离线首轮筛选

暂停语义路线。不下载新数据，不训练模型，不重新提取图像特征。
固定候选顺序与已有Pair-VPR分数，从top20结果决定是否扩展到top44。
决策函数只接收20个已计算分数，禁止输入后24个分数和GT。

首轮仅测试top1与top2配对分数差（不称为校准概率）。在GSV2048上不用GT计算
差值的25%、50%、75%分位阈值，低差值查询扩展到44。50%是主要规则，
另外两条为探索性预算点；全部阈值先落盘锁定，再读Pitts评分，不能事后挑赢家。
Pitts直接使用GSV绝对阈值，报告真实扩展率，不能在Pitts重算分位点。
同地点的多个好候选也可能差值很低，这正是该简单假设可能失败的原因。

对照：固定K=20到44的完整精度—配对数曲线，以及固定query-ID哈希随机扩展。
随机扩展概率对应GSV设定比例，不保证Pitts实际成本匹配，因此同时提供自适应平均
成本两侧的固定K对照。报告R1、纠错/退化、平均配对数、双向前向次数、相对44节省率。
Pitts按全景分组bootstrap（10000次seed42）比较自适应与44及向上取整成本的固定K。
不使用“不显著”冒充等效；不预先宣称达到非劣效或稳定收益。

第一轮只衡量准确率与配对次数，不能推断墙钟加速，因为动态调度改变dense缓存命中率。
GSV/Pitts都已历史暴露，属于探索性迁移；本轮没有独立验证或新颖性证明。
若主要规则被同等/更低成本固定K支配，就不部署、不继续在Pitts调阈值。
