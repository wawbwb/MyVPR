# CLIP 动态语义接入 Pair-VPR：接口审查

日期：2026-09-13。本次仅审查源码与已有结果，没有训练、提取特征或运行新评测。

## 结论

官方 Pair-VPR 没有“局部匹配列表 → 各匹配分数求和”的接口。现有 MNN 连线是诊断脚本额外计算的 encoder token 余弦匹配，删除连线不会改变官方分数。因此，不能直接实现此前表述的“过滤错误匹配证据”。

存在可干预的交叉注意力接口，但它只能支持一个待验证假设：降低 CLIP 动态区域对成对评分的贡献，可能改善真假候选的分数间隔。注意力权重不等于局部正确性或最终分数贡献；代码可实现不代表机制已成立。

## 源码核验与计算路径

- `pairvpr/models/tools/blocks.py`：`a1eaaed8f51aef4039c0ef1809367ad8b7d5530d758e57541d3f6e5a03c5e3f8`

来源：[模型源码](https://github.com/csiro-robotics/Pair-VPR/blob/fd764f9dbc8d210cd0e24c33ea688d6ddc0b3021/pairvpr/models/pairvpr.py)、[注意力源码](https://github.com/csiro-robotics/Pair-VPR/blob/fd764f9dbc8d210cd0e24c33ea688d6ddc0b3021/pairvpr/models/tools/blocks.py)。

`global` 模式返回 dense map 与归一化全局描述子。旧配置图像为 322×322，dense map 为 23×23 token。`pairvpr` 模式将两幅 dense map 投影并加位置编码，仅在第一侧添加 decoder CLS；经过 12 层 decoder，最终取 CLS，经两层 MLP 输出一个标量。

每层依次执行第一侧自注意力、读取第二侧的交叉注意力、逐 token MLP，第二侧 memory 不被该层更新。底层 MemEffCrossAttention 接受 attn_bias，但 DecoderBlock 和模型 forward 没有向外暴露它；需要明确包装该路径。默认 xFormers 不返回注意力矩阵。直接关闭 xFormers 也不能当作已验证方案：该版本 CrossAttention fallback 的调用参数与定义不一致。

已有诊断使用正反向分数之和。实施时必须核对官方评测的排序方向，不能照抄模型里“0 similar / 1 different”的注释。已有 MNN 结果不包含 decoder Q/K/V 或注意力，不能仅靠已下载 JSON 完成干预。

## 与失败实验的关系

交叉评测中，同一 checkpoint 下空间打乱比语义剔除分别多 4、2、5 个正确查询；所有九格均低于冻结 RU 的 675/740。继续提高全局 token 删除强度没有现有依据。

Pair-VPR 原始重排为 693/740，其自身 global 为 639/740。新干预必须与同一 Pair-VPR 的 693 比较；超过 RU 的 675 不能算 CLIP 的贡献。原 top100 包含 GT 的查询为 724，其中 31 个是当前可达但排错的查询，另 16 个错误无法靠固定候选重排挽救。

## 建议的下一次最小诊断（尚未实施）

优先只干预最后一层交叉注意力的 CLS 行，保留所有 token、自注意力、前 11 层、全局描述子和原 top100。这个位置直接进入最后的 CLS 更新，干预范围清楚，且无需重新训练。它并不能清除前层已经混入 CLS 的动态信息，负结果也只能否定这个局部接口。

候选形式为对 memory token j 的 CLS 注意力 logit 加 `log(1 - alpha * d_j)`，其中 d_j 是冻结 CLIP 的动态分数，alpha 固定为 0.5 作为单一探索设定。d_j 不宣称是校准概率。正反两次评分分别使用各自 memory 图像的语义图；不把 CLS 当成有空间位置的 patch，也不把此法叫作逐匹配点过滤。最终仍使用原双向分数合成方式。

必要验证顺序：

1. alpha=0 的包装路径复现原输出；若重建注意力，先核对它与原 xFormers 输出，再分析语义作用。保留原权重哈希与候选列表。
2. CLIP 自动识别外部车辆与行人，不新增引擎盖标注或专用检测。沿用已经冻结的语义生成规则，记录空间变换；旧 RU 的 20×20 网格不能直接当作 Pair-VPR 的 23×23 网格。查询和候选图都需要对应语义图，需先检查缓存的图像 ID 覆盖。
3. 对比不干预、对齐语义、多个固定种子的空间打乱。打乱保持分数分布；另报告其与原图重叠，不能称完全无语义。均匀 logit 偏置会被 softmax 抵消，不构成有效抑制对照。
4. 用所有 31 个可达错误及成功查询作机制检查，不能只看旧的 10 个 GT 选定案例。若为节省成本只检查原最佳正候选与原最佳负候选，报告的是固定候选分数间隔变化，不报告新 R@1；真正重排需对完整 top100 一致评分。
5. 主要看语义干预是否比打乱更稳定地提高正负分数间隔，并检查原正确查询的损失。GT 仅用于分析，不进入推理门控。没有选择性证据就停止，不立即转入训练或阈值扫描；有信号再做完整候选评测及独立数据验证。

这是一项分数干预诊断设计，不是已证明有效的新方法。本次没有创建 GPU 运行脚本，没有需要训练机同步或执行的新实验。
