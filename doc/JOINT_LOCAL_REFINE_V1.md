# 创新点1与局部—全局细化的联合适配V1

2026-10-24用户要求换方案，强调参考两篇ReID模块可叠加，授权继续实验。ReID和VPR都是度量检索任务，模块迁移有合理动机，但不保证变体保留原论文的互补性：两者的目标数据、视角、损失、模型冻结方式均不同。

本轮重新检验第二篇本地ReID稿§2.4式14–15的融合后LGGR思路；借鉴其融合模块共同优化的训练条件，而非再次改变BoQ或训练分支选择器。第一篇稿件的跨层融合变体已构成创新点1；原稿是联合优化体系，不能假定所有后加模块在冻结创新点1后仍有效。不是两篇原方法复现，也不宣称LGGR、联合微调或tanh限幅本身新颖。

## 结构及实际幅值限制

RGB→冻结DINO→创新点1 C-neck副本→新增低秩局部—全局细化→冻结原BoQ→12288维单位描述子。只用一个编码器，独立单图检索，无语义、额外分支检索、排名融合或选择器。原创新点1checkpoint始终只读，各组训练独立副本。

新增模块：逐位置非仿射LayerNorm，1×1投影768→64得到H；DWConv3×3(H)乘H，再乘全图GAP(H)经64→16→64、GELU、tanh得到的通道门控。零初始化无bias的64→768升维得到raw。新残差：

```
delta = 0.01 * stopgrad(RMS_channels(F)) * tanh(raw)
output = F + delta
```

这里0.01是实际逐位置L2相对上限，不是上一轮KV中可被学习权重抵消的名义缩放。仅新细化残差≤当前F范数1%，不保证BoQ排序不变；C-neck自身仍沿用原始2.5%相对DINO末层的上限，不能把联合方案总变化声称≤1%。记录副本neck相对冻结创新点1的实际漂移。

新增模块100928参数（down49152、local576、gate2048、up49152）；实现时实测确认。上游随机非零，仅up零，初始应精确复现创新点1。比原LGGR增加低秩投影及真实幅值控制，不称原公式逐字复现。

## 四组对照

|组|创新点1 neck副本|新增模块|问题|
|---|---|---|---|
|neck_continue|训练，lr1e-5|无|额外继续训练能否解释收益|
|frozen_refine|冻结|训练，lr1e-4|固定创新点1后叠加是否有效|
|joint_refine（主候选）|训练，lr1e-5|训练，lr1e-4|两部分共同适应是否有额外价值|
|joint_permuted|训练，lr1e-5|训练，lr1e-4，局部置乱|检验真实空间邻域|

joint两组严格同参数与初始张量，局部DW计算前按图像SHA置换，计算后逆置换，保持值—位置对应而破坏邻接。global GAP不打乱。其他组可训练容量不同，明确报告；不得把joint对冻结组差值单独归因结构。neck原aux头保持冻结，未参与前向的参数不放入优化器。原DINO/BoQ及原anchor全只读。

## 固定预算与判据

seed42，封存8192地点、四视图、16地点/批、322，原计划前1024步，所有组同顺序同预算；每组8步smoke丢弃，正式从同一归档创新点1与新零头开始。AdamW wd0，FP32，clip1，microbatch2，完整64图GPS过滤MS损失，无辅助、RATR或余弦保持。每16步可恢复保存，不按验证选epoch或调整上限。1024步约两轮是首筛预算，不与历史2560步混称等预算。

记录非零检索loss步、有效难负数、所有训练参数梯度、新残差幅值、neck漂移和描述子漂移；机械检查原anchor、各组aux和冻结组neck不变。先服务器CPU测试和8步smoke，通过后正式训练并三套完整验证。

固定最终步GSV留出、MSLS740、Pitts7608完整图库。创新点1基线必须复现3049/695/7276和完整Top20。主候选须在Pitts严格胜过创新点1及三训练对照，MSLS不低于创新点1及三对照，GSV不低于创新点1，才为探索性信号；否则不能声明组合有效。若neck_continue解释收益，只支持继续适配；joint与permuted持平，不支持真实邻域贡献；frozen同joint，则不支持联合适应必要性。单seed成功也需独立验证，不自动扩展。

方案改变了适配位置和训练条件，不能把它与上一轮KV结果之差单独归因为限幅，归因以本轮对照为准。旧单DINO交互也含局部/全局细化但冻结创新点1，本轮不宣称首次引入该算子，而是简化模块并检验联合适应条件。
