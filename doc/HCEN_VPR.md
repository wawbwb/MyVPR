## 来源及问题

来源为本地私有稿件 `doc/B2609209 (修改稿).pdf`《多尺度特征融合的 Mamba-Transformer 行人重识别网络》。重点参照 §1.2 HCEN/MFM（图2/图3）、§1.3 SASF（图4）、§1.4 的辅助监督及式19–24排序正则。论文、图片及提取文本不提交至公开 Git；实验仅记录原稿 SHA256。

表2中 Market-1501 的 mAP/Rank1 从88.3/94.9逐步提高至89.9/95.6；MSMT17从63.1/82.0至66.1/84.1。这些是作者稿件报告的 ReID 结果，非本项目独立复现，也不能保证迁移到 VPR。

可借鉴的是：浅深特征并非独立拼接输出，而是逐级融合；融合保留二维结构；中间层得到可用的训练信号；避免各分支只复制同一种排序。不是把检索任务相似性等同于数据分布相同。行人裁剪通常具有较稳定人体布局，VPR 存在更剧烈视角、遮挡、尺度及相邻地点标签歧义。

此前 SLGD 分解中，训练后“全局+固定20%局部拼接”在6144查询上比各自全局分支少93–96个正确，固定RU全局搭配该局部也少44–48个。当前首先取消独立局部描述子拼接；冻结原RU权重，检验特征图层面的跨深度融合。此前 L10 直接替代/指导未产生可重复净收益，不代表渐进式联合利用不同深度必然无效。

## 网络与论文的区别

```text
冻结 RU DINOv2
  L8 ── LN/投影128 ─┐
  L10 ─ LN/投影128 ─┴─ MFM + SASF ─ G10 ─┐
  L12 ─ LN/投影128 ────────────────────────┴─ MFM + SASF ─ G12
  L12 + 0.1 × 每patch RMS(L12) × tanh(零初始化升维(G12))
      → 冻结原 RU 空间门控 → 冻结原 BoQ → 单个12288维单位描述子
```

原DINO、RU门控和BoQ参数全部冻结，但门控/BoQ保留对输入特征的梯度。零初始化升维严格复现原RU；逐patch RMS/tanh使特征改变量相对L2不超过0.1。这个约束不是排序保持证明，也不保证指标不下降。

两级 MFM 对低层分支作额外残差深度卷积，拼接128+128后进行行/列及反向的共享选择性状态扫描，同时设置二维深度卷积分支，再拆为低/高分支增量融合。SASF含3×3(dilation1)、5×5(dilation2)两个深度可分离卷积路径及可学习softmax权重。

这里 L8/L10/L12 均是原生20×20网格，属于**跨深度特征**，不能宣称真实多分辨率金字塔。扫描复用项目纯PyTorch对角Mamba-1参考递推，O(L log L)，不是论文官方 MambaVisionMixer 或 fused CUDA 的逐行复现；不更换骨干，不下载新权重，不新增环境。MambaVision的混合层次结构可参见[官方实现](https://github.com/NVlabs/MambaVision)，但本实现不是其预训练模型。

G10/G12各有一个训练期256维均值池化投影头，使用现有GPS过滤的MultiSimilarity损失作深监督，推理弃用。不同于原稿ID交叉熵+Triplet，避免新增巨大闭集身份分类器。主描述子仍用相同MultiSimilarity，辅助两头平均权重0.1。

### 排序约束的安全适配

原稿最小化软Kendall相关项，可能鼓励负相关。为避免为“互补”破坏已经正确的检索，本实验改为：

- 参照为冻结RU的相似度排序；在同类正样本内部、负类中心内部独立比较，**不打乱正负之间的顺序**。
- 负样本须与查询相距≥25米；负类中心要求该类全部本批图像均满足距离条件。
- 仅在RU最弱正样本比最强安全负样本高0.02时启用。
- 使用 `relu(soft_tau - 0.5)^2`，温度0.02，权重0.02；不奖励负相关。报告有效覆盖、激活率与真实梯度，零激活不能算有效检验排序约束。

这是新的受约束适配，不是原论文RATR复现。假设是“有约束的跨深度融合可引入有用而非冗余的细节”，尚无VPR收益或创新性证明。

## 三组匹配对照

| 模式 | 输入 | 排序正则 | 要回答的问题 |
|---|---|---|---|
| last_only | L12/L12/L12 | 无 | 同参数颈部/Mamba/空间路径本身有效吗？ |
| hierarchy | L8/L10/L12 | 无 | 真正跨深度信息比同参数控制有效吗？ |
| hierarchy_rank | L8/L10/L12 | 有 | 安全排序互补是否带来附加收益？ |

三组同初始化、参数量、零起点、样本顺序、辅助头和优化器。冻结RU为额外固定基准。测试先4步smoke，再每组128步pilot，AdamW lr1e-4、wd0、FP32、clip1、每步8个均匀抽取的训练锚地点+其硬负地点，每地点4张图，最多64张。每4张进行一次重计算以控制显存。复用旧8192地点训练缓存，仅读取其中硬负样本索引；不使用验证正误采训练样本。

本轮是等预算可行性筛查，**不是论文160轮完整训练**。固定末步，不按MSLS/Pitts结果调权重或挑检查点。GSV6144查询/10240图库进行成对统计；另外MSLS740查询/18871图库、Pitts7608查询/10000图库均重算同图像RU基准和学生特征。要求原RU正确数分别675、7160。GSV保持原历史PIL缩放；标准验证单独匹配历史torchvision v2 `ToImage -> Resize bicubic antialias -> float32/scale -> ImageNet normalize`。两种缩放不能混用。所有这些验证集已有历史曝光，不当作独立最终测试；若有正信号，再预注册更长训练和跨seed验证。
