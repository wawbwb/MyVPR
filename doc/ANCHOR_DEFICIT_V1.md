## 网络与代价

`RGB -> 冻结创新点1 -> z0(12288)`；在z0上另接只用GSV训练图拟合的PCA256与新头 `LayerNorm -> Linear256 -> GELU -> Linear128 -> L2Normalize`，输出h。

最终单图描述子为 `d = concat(sqrt(.9)*z0, sqrt(.1)*h)`，12544维。所有查询和参考图像经过同一网络，只需单阶段点积检索，无配对推理、候选扩展或语义模型。

分数满足 `s = .9*s0 + .1*sh`。固定10%是相似度混合权重，不是描述子系数或保证最大漂移。128维新增约1.04%存储，加上PCA投影和MLP计算；原分支冻结不代表检索不可能退化。零融合权重可精确旁路，正式.1权重的随机初始化不等于锚点，所以必须报告随机初始头对照。

这是对现有全局信息的非线性重编码，不提供已经丢失的像素细节；先用已存FP32缓存检验监督假设，可避免盲目重复图像提取。PCA/投影全部仅由训练集确定，不对白化或维数扫参。若此监督假设不成立，不自动追加局部分支。

## 固定排序缺口目标

每条训练查询固定创新点1最相似的同地点正图p，以及旧配对索引中的合法困难负图n（不同地点且>=25m）。负图来自旧FP16选样，但本轮相似度和训练均使用封存FP32描述子。不是当前新模型全库最难负样本。

记锚点间隔 `g0=s0(q,p)-s0(q,n)`，补充分支间隔 `gh=sh(q,p)-sh(q,n)`。设目标融合间隔m=.01，w=.1，所需补充分支目标：

```
t(q) = clamp((m-(1-w)*g0)/w, 0, 1.8)
g_fused = (1-w)*g0 + w*gh
```

锚点已有足够间隔时目标为0，让支路对该固定正负差保持中性，而非再追求大间隔。困难样本得到与缺口对应的正目标。目标上限1.8小于单位向量分数差理论上限2；记录被截断的样本，不保证所有训练约束同时可实现。不使用验证集错误标签制定目标。

训练对gh与目标计算SmoothL1(beta=.1)。以锚点g0<=.05划为hard，其余easy，分别求均值再等权。只优化这一个直接目标，不另加难以归因的辅助/去相关/保持损失。目标0只约束配对分数差，不等于推理侧描述子为零。

## 三个匹配训练组

|组|目标|用途|
|---|---|---|
|constant_target|全部查询gh目标=.1|不使用逐图缺口的固定间隔回归对照，不冒充全部标准度量学习基线|
|deficit_target|真实t(q)|主候选|
|shuffled_target|hard和easy池内分别固定打乱t(q)|保持各池目标分布，破坏目标大小与具体查询的对应；故意错误监督负对照|

三组结构、初始参数、优化器、曝光和难易权重一致。打乱不会改GPS、标签或负样本合法性。候选必须同时胜过固定间隔和打乱目标，不能只胜错误监督组就宣称有效。增加冻结创新点1及未经训练的同初始随机头，报告初始混合损伤。

训练端固定配对准入需同时满足：

- 候选修复至少10条原非正间隔查询；退化不超过修复数的一半；
- 修复减退化严格超过另外两组；
- 原hard池平均融合间隔增量至少.001。

这是预先固定的工程筛选条件，不是统计显著性门槛、全库R@1或论文成功标准。失败就停止，不提取验证图像、不补预算或调混合权重。
