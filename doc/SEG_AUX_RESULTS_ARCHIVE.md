# SegAux-BoQ V1 / V2 结果归档

归档日期：2026-09-09。状态：COMPLETED / NO SUPPORTED R@1 GAIN / STOPPED。
这是项目对SegVPR共享编码器联合学习思想的改编，不是原版SegVPR复现。

## 方法与设置

DINOv2最后2个block与BoQ共同微调；RU gate参数冻结，前向及梯度链路保留。
分割头接raw DINO空间特征，无detach；置信度>=0.5的ADE20K伪标签参与confidence-weighted CE。
推理只运行DINO→RU→BoQ。原始RU为675/740（91.22%），权重身份见各contract。
两版本均采用P40/K4、280×280、photometric增强、seed42、FP32，联合训练5轮。
骨干/BoQ lr=2e-6，分割头lr=1e-4，最终lambda=0.02。

- V1：随机分割头直接联合训练。
- V2：先在冻结检索网络上预热分割头500步；重新初始化联合优化器和数据seed；
  联合训练前1000步语义权重从0.00002渐增到0.02。对照仅做5轮VPR微调，
  匹配检索更新预算，不匹配额外预热算力。

## 结论与停止决定

语义被学习，初期梯度问题得到缓解，但最佳R1仅持平冻结RU、最终少4个query。
相对VPR-only的最终优势只有1个query；可能缓解部分微调退化，但证据不足。
当前配置不继续加epoch、扫权重、启动shuffled或额外梯度处理模块。
此结论只约束当前伪标签+强RU基线的具体设置，不否定原版SegVPR或全部语义方法。
