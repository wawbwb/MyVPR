# BoQ前的训练期CLIP变化约束：三组探索性实验

## 依据与边界

2026-10-18完成的表示诊断中，冻结官方BoQ的最终12288维描述子在固定探针下训练R²=0.7728、地点留出R²=-0.4964；BoQ前768维patch均值的留出R²=0.3020（地点bootstrap区间0.2943–0.3099），打乱目标对照=-0.0133。2×2池化为0.2632。完整描述子的失败不是单纯256维投影造成，亦不能证明BoQ完全删除了所有信息。

因此提出**新的、独立的训练位置假设**：在聚合前可训练的视觉表示上约束跨视图变化。旧全局描述子方案依然保持停止，未改动其阈值、代码、缓存或结果。

CLIP目标来自同地点四张图的池化SCLIP向量，地点内中心化，再用仅训练集拟合的32维PCA白化和裁剪。它混合视角、可见内容和外观变化，**不等同于纯干扰真值**。可预测性不是抑制它一定能提升检索的证明。

## 网络与目标

推理：RGB → 冻结官方DINOv2 → 新残差适配器 → 冻结官方BoQ → 12288维单位全局描述子。

适配器：768→64的1×1卷积，GELU，64通道depthwise 3×3卷积，GELU，64→768的1×1卷积，输出乘0.1后残差相加。末层权重/偏置置零，使初始描述子复现官方网络。只有适配器99,776个参数可改变；不修改原BoQ注意力、查询、值特征计算代码或DINO权重。

训练预测器：适配后的patch均值 → 地点内中心化 → 固定训练集原始特征标准差归一化 → 768→128→32 MLP。它只用于训练，其参数102,560；不参与推理。

预测器最小化变化回归MSE，每次学生更新前做两次detach后的预测器更新。学生最小化地点监督MS损失及0.1×官方描述子余弦保持损失，同时通过梯度反转最大化预测MSE。对抗系数在512次更新内从近零线性升至0.02。学生lr=3e-4，预测器lr=1e-3，AdamW无weight decay。固定FP32；所有超参数在此次训练前锁定，不按开发集调节。

## 对照、数据与预算

|组别|新适配器|预测器训练目标|学生对抗系数|
|---|---|---|---|
|visual|相同结构及初始参数|真实对应变化|0|
|aligned|相同结构及初始参数|真实对应变化|升至0.02|
|shuffled|相同结构及初始参数|地点内其他视图的变化|升至0.02|

三组预测器相同随机初始化；都更新预测器，避免额外训练计算不匹配。shuffled是固定四视图无固定点置换，保留地点内目标分布；它不是独立随机噪声，中心化残差可能存在反相关。不能将它的收益自动解释为“语义反向使用有效”。

复用已封存GSV计划：8192个训练地点×4视图=32768张图，1024个地点留出×4视图=4096张图；P16×K4，5轮，三组各2560次更新。不是完整GSV训练，也不保证与官方预训练地点互斥。固定末轮评测，不按最佳轮次挑选。

先做服务器CPU测试，再三组各8步机械smoke，全部通过后重新从同一初始化进行正式训练；smoke权重不带入正式训练。训练串行，限制物理GPU1、单进程20%显存；不终止其他进程，不使用GPU0，不缓存稠密patch到磁盘。

为低显存使用梯度缓存：第一遍无梯度产生全批次描述子及patch均值；在这两个叶子上计算全批次损失及梯度；逐microbatch重算适配器和冻结BoQ，将两个输出的梯度共同回传。网络不含新dropout/BN，冻结BoQ保持eval；CPU测试比较重算与直接反向梯度。每16步原子保存适配器、预测器、两个优化器、步数和RNG，可在相同契约下恢复。

## 评测与判定

自动评测官方、visual、aligned、shuffled四组。仅GSV适配留出、MSLS-val、Pitts30k-val，不访问盲测。保存完整Top20、逐查询纠错/退化和配对结果。

完成后丢弃原预测器，用各组的适配后768维均值、各自仅训练集拟合的尺度，重新初始化相同探针，在真实CLIP变化目标上训练固定8轮，再于地点留出评测。探针不按留出结果选轮。更低R²只是机制诊断；若检索不优于等容量visual，不能宣称变化约束有效；若打乱也有相同收益，不能归因于正确CLIP对应。单种子和反复使用开发集的结果不是稳定泛化结论。

原始官方权重、创新点1七个核心源文件、专利初稿、旧实验和封存缓存全部只读。新输出：`logs/clip_preboq_v1`；任务状态：`.cache/clip_preboq_launcher_v1/progress.json`。
