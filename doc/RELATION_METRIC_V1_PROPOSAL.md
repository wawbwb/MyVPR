## 2. 新假设及与旧方案区别

问题：创新点1的最终描述子中，同地点跨视图变化与相似不同地点之间的差异，
是否能提供可学习的度量方向，使少量、受控的描述子校准改善检索？

这是“聚合后已有表示是否还可校准”的新位置假设，不是已经证明BoQ是瓶颈。
不添加图像语义，不引入第二编码器，不再生成局部/二阶新描述子，不改变候选检索算法。

```
RGB -> 冻结DINO + 冻结创新点1 + 冻结BoQ -> z0（12288维单位向量）
                                                  |
                                   固定关系子空间U，投影64维
                                                  |
                                   单图条件化的有界方向缩放
                                                  |
                               加回z0并归一化 -> z（仍12288维）
```

训练标签只用于估计子空间及检索监督，推理只输入单张图像。
查询和数据库都使用同一个模型，无查询GT、GPS、外部候选集合或批次统计。
数据库需重新生成变换后的描述子；维度相同不等于无需更新数据库。

## 3. 固定关系子空间

仅使用封存GSV训练8192地点的32768图，先由创新点1产生FP32单位描述子。
原FP16银行只可用于先导诊断/现有选样，不直接作为正式训练数值依据。
FP32原始训练矩阵约1.5GiB；先盘点已有FP32缓存，缺失才提取一次，不产生dense patch缓存。

1. 用训练描述子拟合256维PCA正交基P（流式/随机SVD固定seed42），仅用于估计子空间。
2. y=P^T(z0-mu)，mu仅训练集拟合。
3. W为同地点不同视图差向量的平均外积。每地点4图的6个无序对等权，地点等权。
4. B为查询与其预定困难合法负样本差向量的平均外积；异地点且距离>=25m，
   使用现有image_negative配对索引并核验行号映射，不读取任何验证标签。
5. S=B/(trace(B)+eps)-W/(trace(W)+eps)，eps固定1e-8。
6. 取S绝对特征值最大的64个正交特征向量V，U=PV，满足U^TU=I。

保留两种符号的方向，由训练学习增强或减弱，不把同地点变化全部硬删。
同地点不同视图仍可能缺少视觉重叠，W不能命名为“纯干扰协方差”；
B也不保证完全没有地理标签噪声。这是需要验证的归纳偏置。
推理校准使用U^T z0，不做整向量去均值；零校准时严格返回原z0。

## 4. 有界校准层

令u=U^Tz0，a(z0)=0.05*tanh(g_theta(u))，

```
delta = U [a(z0) * u]
z = L2Normalize(z0 + delta)
```

实现采用 `z0 + normalize(z0 + delta) - normalize(z0)` 的括号差形式，
避免FP32输入的微小范数误差导致零增量时再次归一化改变描述子。
零增量逐元素精确复现锚点；非零增量检查单位范数误差，不声称数值上严格单位化。

g为64->32->64的MLP，GELU，无跨图像操作，输出层零初始化。
若输出权重与bias都为零，初始delta=0，模型精确复现创新点1；
前层梯度首步为零是零初始化的正常现象，smoke应检查后续步骤传播。

U固定且列正交，则归一化前 ||delta||2 <=0.05||U^Tz0||2 <=0.05。
该界不保证归一化后的距离同样<=0.05，更不保证检索不退化。
垂直于U的分量在归一化之前保留，归一化后仍会被公共尺度影响。
0.05是本次待登记设计值，不能根据MSLS/Pitts结果事后扫描修改。

MLP约4192个可训练参数；固定U含786432个数，FP32约3MiB，
U^Tz和Udelta每图合计约157万乘加，不称为零成本。

## 5. 匹配对照，避免只验证“又加一个MLP”

冻结创新点1单列为基线。四个训练组：

|组别|固定正交子空间|方向缩放|检验|
|---|---|---|---|
|random_basis|固定随机64维正交基|同一个MLP结构|任意受限容量是否已足够|
|pca_basis|训练描述子的前64个PCA方向|同一个MLP结构|无监督主要变化是否已足够|
|relation_static|关系基U|64个图像无关可训练系数|全局度量重加权是否已足够|
|relation_conditional|关系基U|同一个MLP结构|关系方向加单图条件化是否有额外作用|

前三个含MLP的组（random/pca/conditional）严格同初始化/参数量/训练数据/预算。
static只有64参数，明确不是等容量对照；不通过无用参数填充。
同时必须包含常规正则化监督白化基线，否则无法排除已有方法解释。
令P64为同一训练PCA的前64维，W64为其匹配对差协方差；
C=0.9 W64+0.1 trace(W64)/64 I，特征值下限1e-8。
C=Q diag(lambda) Q^T，s_j=exp(mean(log(lambda))/2)/sqrt(lambda_j)，
b_j=0.05*tanh(log(s_j))。输出为
normalize(z0+P64 Q diag(b) Q^T P64^T z0)。
该对照保留子空间外原分量，限制谱变化，全部统计只用训练集。
它是固定的“有界子空间白化对照”，不冒充原论文全维/降维白化的完整复现。

所有组直接从创新点1零增量开始，不读取structure_gate或hard_protect的适配器权重。

## 6. 训练与数据隔离

冻结整个图像模型，所有组只训练描述子校准层，可从FP32缓存直接训练。
使用原GSV训练日程、固定困难配对、64基础图+64负样本槽位。
不将验证错例加入训练，也不只训练曾被修复的查询。

首筛保持image_negative的监督组合：基础64图GPS过滤MS损失，
全部128图0.1余弦保持，配对softplus项权重0.1、margin=.05、temperature=.05。
不再叠加选择性排序保护，以隔离新校准表示；相对旧实验的差值不作纯单因素因果结论，
归因以本轮各组相同数据和损失的比较为准。

固定seed42，AdamW lr3e-4、wd0、clip1，512步、FP32，最终步评测。
描述子缓存允许全部端点的校准层有梯度，但不会更新冻结的图像模型。
需先核对重复负样本、同地点正样本与微批重放实现，不把同图副本当负样本。

阶段顺序：
1. 只读盘点缓存和来源，建立新合同；不修改旧源文件/缓存seal。
2. 描述子FP32一致性检查，拟合训练子空间；不使用MSLS/Pitts统计。
3. CPU数学测试和8步丢弃式smoke：旁路一致、正交界、两端梯度、实际门控活动。
4. 四组各512步训练；静态白化不占优化步，不夸称同训练预算。
5. 完整GSV留出3072查询、MSLS740/18871、Pitts7608/10000评测一次。

FP32 eval缓存若没有，可共享一次冻结创新点1图像前向，同时输出六种校准结果。
不能用原FP16银行完成小幅+1的正式排名结论。缓存和同图不同批次推理误差需记录。
不承诺耗时；主要开销可能是缺失FP32缓存的提取和完整全库排名，而非小头训练。

## 7. 成功、归因与停止条件

第一道：relation_conditional在Pitts严格超过7276、在MSLS不低于695，GSV不低于3049。
这是开发计数准入，不是统计非劣效或稳定性证明。
第二道：Pitts严格超过random、pca、static、有界白化对照，且MSLS不低于这些对照。
若只static/白化有效，只说明常规度量校准有用，不声称条件关系模块创新成立。
若conditional与pca相同，不声称关系方向有效；若与static相同，不声称单图条件化有效。

记录R@1/5/10/20、逐查询修复/退化、残差范数、门控分布及饱和比例、
低间隔/原正确与错误的完整分层（仅诊断，不据此挑推理子集），延迟与存储。
单种子多一两条仅为后续复核候选。通过后再固定协议补seed43/44及真正未用于开发的测试集。
所有当前开发集均多次观察；Pitts-test是否未用需核查，不直接宣称盲测。

若失败或只改善已经退化的控制组，本轮停止，不自动扩大rank/幅值/epoch、扫参数或增加分支。
失败会说明这个固定描述子低秩校准配置没有通过，而非所有度量学习无效。

## 8. 新颖性边界与参考

- Radenovic等，Fine-tuning CNN Image Retrieval with No Human Annotation：
  https://arxiv.org/abs/1711.02512 。已有监督判别白化和困难正负样本，
  “在描述子后加监督变换”不是新贡献。
- Zhu等，Attention-based Pyramid Aggregation Network for Visual Place Recognition：
  https://arxiv.org/abs/1808.00288 。VPR已有PCA power whitening，不能把白化重命名为创新。

本提案候选贡献仅为：在强冻结VPR锚点上，以跨视图/困难地点关系定义受限方向，
学习单图条件化且有界的同维校准，并以匹配消融证明相对普通度量变换的增量。
当前检索不是穷尽性新颖性审查，此组合有价值/有新颖性均待验证。
若论文要求新的局部空间网络模块，本提案不满足该结构偏好；它研究的是全局描述子几何。
