# 创新点1后接跨分辨率差分细节注入：V1

2026-10-25，用户授权参考已有失败结果设计新方案并继续实验。此为单种子开发实验，不保证成功，不将多尺度或普通残差映射本身称为论文创新。

## 从失败结果得到的设计变化

通道/矩保持/联合细化/全图库监督没有形成超出对照的净收益，KV适配产生较大变化也退化；最近空间位移的微弱R@1变化可由训练集平均固定平移复现。聚合查询竞争去重复在更早CD-BoQ中也已有负结果。本轮检验另一问题：主路322缩放损失的输入细节能否通过更细采样补充，而不是继续只用同一23×23特征变换已有信息。

创新点1使用同一网格的L8/L10/L12，属于跨深度。本轮保留其全部权重，使用同一冻结模型另做518输入前向，得到37×37特征。新的分辨率路径与原跨深度路径不同，但互补和可叠加性必须由实验建立。

多分辨率VPR已有[MultiRes-NetVLAD（RA-L 2022）](https://arxiv.org/abs/2202.09146)。两篇内部ReID稿件的跨层/多尺度交互启发了问题拆分，不是本方法完整复现或性能保证。当前候选贡献限于“对齐差分注入是否优于简单多尺度与同容量对照”，完整新颖性审查尚未完成。

## 模块与信息对照

同图完整缩放，无裁剪、翻转、随机增强。主路按既有transform直接得到322，补路从原RGB直接得到518。另将已归一化322图用bicubic、antialias放大至518，作为没有新增原图采样细节的控制；该控制仍会改变DINO采样网格和上下文，不能称与322特征相同。

令F为322的创新点1增强图，H为518增强图。area池化把H对齐到23×23；这保留相同归一化坐标的大致空间覆盖，不是跨图像几何配准。定义逐patch无仿射LayerNorm后的差分：

```
D = LN_channels(area(H, size(F))) - LN_channels(F)
raw = Conv_32_to_768(GELU(Conv_768_to_32(D)))
F_out = F + .025 * stopgrad(RMS_channels(F)) * tanh(raw)
```

两个1×1卷积均无bias，输出卷积全零初始化，每组49,152有效参数。差分为0时新增残差严格为0；零起点复现创新点1，实际逐patch及整图相对L2上限2.5%。不改变DINO/原neck/BoQ，不新增语义、外部模型、候选交互或描述子维数。差分包含采样细节、尺度和上下文变化，不能直接视为纯高频或新增地点信息。

|训练组|输入差分|检验|
|---|---|---|
|degraded_detail|322放大518的增强图与F之差|同容量、同细网格前向但没有新增原图采样细节|
|aligned_detail（候选）|原图518增强图与F之差|原图细采样补充是否有价值|
|shuffled_detail|将候选差分的完整通道向量按图像SHA打乱位置|空间对应是否必要|

三组相同参数、初始张量、数据顺序、检索目标、优化器及预算。shuffled保留差分向量分布，实际残差与F的RMS相乘后不保证完全同分布。degraded与真实差分分布也不完全匹配，结论只能覆盖这个具体信息控制。

## 简单替代与固定评测

额外评测不训练的innovation1_518，以及`normalize(z322+z518)`的等权描述子平均。两者用于防止将直接增加分辨率或常规多尺度收益误归新模块。所有版本都输出12288维单位向量；518使用原冻结neck的分辨率外推，不声称它在518重新训练或已最优。无需扫描融合比例。

原8192训练地点、每地点固定四图、16×4完整批，种子42，FP32微批2，前1024步；8步真实smoke丢弃。AdamW lr1e-4、wd0、clip1，仅GPS过滤MS检索损失。无附加教师、原型、保持或去相关损失，无验证选择checkpoint。每步三种尺度/信息输入共享冻结编码结果，三训练组独立优化器。只有一套DINO权重，候选推理需要两个编码前向；全对照实验每图做三个前向，明确增加计算，不声称免费或单次编码。

最终完整GSV留出3072查询、MSLS740、Pitts7608，原图库及GT。322基线必须完整Top20精确复现旧报告。候选Pitts正确数须严格超过基线、两个训练对照、518直接检索与等权平均；MSLS不低于全部这些版本，GSV不低于322基线，才记为探索信号。该严格计数条件不是统计非劣证明或多次开发后的独立确认。
