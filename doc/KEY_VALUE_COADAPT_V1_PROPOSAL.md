# 第二创新点新候选：融合特征的键值协同校准

状态：依据两篇本地参考PDF和失败记录重新设计；本文件是研究方案，不是已实现/已验证成果。本轮不启动训练。

## 1. 先修正对通道实验的解释

旧seed42通道适配相对官方BoQ在Pitts纠错16、退化3，其中9条纠错已被创新点1覆盖，确有收益重叠。但原版初始化接入创新点1后仍能纠错9条，同时退化12条；最终7273低于基线7276。因此“完全重合所以没有变化”不成立。现象是有新增纠错，但退化更多。

官方最后层特征与C-neck输出不同，适配后又送入冻结BoQ，可能发生表示与聚合器之间的不协调。尚未做足够因果对照，不能把这种可能性写成已证实根因。原通道本身也并非跨数据集均成功（MSLS693低于官方694）。

## 2. 从两篇论文借鉴什么

本地B2609209修订稿§1.3.2，式19–24：RATR对骨干与融合分支的相对排序相关性施加约束，且与判别监督共同训练。它支持“互补性必须受学习目标检验”，不证明强制负相关适用于VPR；本轮不再引入排序反相关损失。

本地异构双分支ReID稿§2.3–2.5，式12–15、19：动态低秩残差、投影后局部—全局细化与多输出直接监督，且骨干与融合模块联合优化。这里借鉴的是融合后细化和可适配的后续读出；不复制MambaVision+OSNet，不把冻结DINO中间层当作真正异构骨干。

创新点1已经借鉴跨层条件补充。第二点应针对“如何聚合融合后的特征”，而非再次叠加同类通道变换，亦不转成模型选择/双分支排名融合。

## 3. 总体结构

RGB → 冻结DINO → 冻结创新点1 C-neck → 原BoQ投影与token encoder → **新增键值协同校准** → 原learned-query cross-attention → 原输出投影 → 12288维全局描述子。

新模块置于每个BoQ block的视觉token encoder之后、cross-attention的K/V投影处。保留原Q/K/V权重、查询向量、self-attention和FC；只学习新增校准参数。推理单图、单编码器、单描述子、直接检索，无查询—图库交互。原BoQ权重仍冻结，但其有效注意力聚合函数因新增残差可学习，因此不再是完全固定的读出映射。

设encoder输出空间token为X，D=384（须实现时以归档官方权重核实），原投影为Q0、K0、V0。新增低秩r=32：

```
H = D_down(LN_nonaffine(X))                       # N×32，恢复原H×W网格
g = tanh(W2 GELU(W1 GAP(H)))                      # 32维，全局条件
H_K = H * (1 + g)
H_V = DWConv3x3(H) * H * g                       # 局部—全局乘性交互
K = K0 + 0.1 * U_K(H_K)
V = V0 + 0.1 * U_V(H_V)
O = softmax(Q0 K^T / sqrt(d_head)) V
```

投影按原head维度拆分；原attention输出投影及bias处理保持一致。K分支调整关注位置，V分支调整聚合内容；二者共同接受最终描述子检索损失。K/V仍可访问相同输入，不宣称自动获得语义分工或独立互补。

LN无可训练仿射；所有新线性/卷积无bias。全局门控32→8→32。两个U零初始化，其余路径非零初始化，避免双零锁梯度。零起点使用原内核输出加“新手算attention−原手算attention”差值，要求真实图像描述子误差≤1e-6；手算差值需保留K/V梯度，不能简单在零值时return绕过。关闭dropout，做逐head数值和梯度对照。

两块预计参数：每块down12288、DW288、gate512、两up24576，共37664；两块75328。此数值依赖实际D/head/grid核实，不能把计划值当实测。非线性/空间门控不可像普通线性LoRA一样整体合并为常数权重，需实测推理额外成本。

## 4. 与历史失败方案的区别

|已有路线|已有局限|本轮改变|
|---|---|---|
|pre-BoQ通道/门控/矩保持|patch更新后由固定读出解释；未有净收益|直接适配cross-attention内部K/V|
|CLIP-Key|外部语义路由，固定Value|只用创新点1视觉token，K/V共同适配|
|LCV-BoQ|固定原Q/K权重，仅原注意力聚合新增局部值；旧RU基座|在当前创新点1上联合更新路由和内容；LCV式value-only保留对照|
|竞争查询CD-BoQ|重分配已有attention以去重复，已无一致收益|不以槽位竞争/注意力去冗余为目标|
|低秩全局度量/二阶旁支|只改最终描述子或另建读出|修改融合特征的内部聚合映射|
|可靠性选择/RRF|偏离单模型模块叠加、监督分歧不足|最终描述子的地点损失直接训练新模块|

上述区分只说明本地实验条件不同，不证明文献新颖性。RATR损失、LGGR组件及低秩适配均已有先例。

## 5. 必要对照与归因

固定冻结创新点1作为基线；四训练组都在同一创新点1上，从零残差重新开始：

1. Plain-KV：普通独立线性K/V LoRA，rank24，两块73728参数。检验普通聚合器适配是否足够。
2. Value-only：上述模块去掉K增量，保留LGGR式Value分支和共享down/gate；未用的U_K不注册/不优化。两块50752参数。它参数更少，只能作为方向性机制消融，不能把差值全归因K。
3. Local-KV：上述完整方案，预指定候选，两块约75328参数。
4. Permuted-KV：与Local-KV同参数、同初始化，只有DWConv局部分支在固定逐图空间置换后计算，再逆置换恢复位置；破坏邻域而保持K/V位置对应。门控GAP保持相同。必须在非零权重上确认该对照确实改变输出，不能使用对GAP无效的空间打乱。

Plain-KV与候选有1600参数差（约2.17%），如实报告，不能称严格同容量；Local/Permuted是严格匹配的空间机制对照。不得增加无用参数凑数。

如果只有Plain-KV提高，说明普通有效读出适配值得研究，不支持LGGR式结构必要性；如果Local/Permuted相同，不支持空间对应关系的额外作用。Value-only若已经解释收益，也不能声称联合K/V必要。

## 6. 第一轮训练和成功条件

第一轮固定seed42、原8192地点计划、16地点×4图、322输入，四组各2560步；每组8步smoke丢弃，正式重新初始化。新参数AdamW lr1e-4、wd0、clip1，FP32，microbatch2但完整64图共同挖掘。仅GPS过滤MultiSimilarity地点损失，不加RATR、辅助头、余弦保持或验证集错误专用目标。既有创新点1一切参数及状态冻结。

这种数据在全库检索中已接近饱和，训练过程中必须报告MS有效步、有效难负数、K/V实际更新与梯度、残差规模及描述子漂移；当前协议不足不是靠额外辅助损失掩盖。smoke须确认两输出投影后上游各层收到梯度。若没有有效训练信号，报告该限制，不能只凭程序跑通宣称机制经过验证。

固定最终步完整评测GSV适配留出、MSLS-val、Pitts-val，基线Top20必须复现3049/695/7276及既有完整预测；不按MSLS/Pitts选epoch或扫rank/权重。预指定Local-KV在Pitts严格超过创新点1及三对照，MSLS/GSV不低于创新点1，且MSLS不低于三个对照，才算第一轮探索信号。多种子和独立未反复开发数据另阶段；单seed过关不等于论文成功。

只在GPU1运行、20%分配上限和额外2GB余量，旧实验锁，独立源码/输出。实现前后不得改写创新点1归档。用户当前请求为方案，本轮不自动编写训练代码或启动任务。

## 7. 文献定位和待验证风险

- BoQ使用学习查询对视觉token cross-attention聚合：https://openaccess.thecvf.com/content/CVPR2024/html/Ali-bey_BoQ_A_Place_is_Worth_a_Bag_of_Learnable_Queries_CVPR_2024_paper.html
- LoRA冻结原权重并插入低秩增量已是既有方法：https://arxiv.org/abs/2106.09685
- EDTformer已在VPR研究decoder聚合及低秩并行适配：https://arxiv.org/abs/2412.00784 。不能把“VPR+低秩+decoder”称为新颖组合。

可检验贡献候选是：针对已冻结多层融合表示，将局部—全局条件增量分别送入键和值，能否产生优于普通KV适配、value-only和几何打乱的聚合收益。不是已成立的论文创新点。注意力的K增量也可能引入新排序退化；零初始化和小幅缩放不保证召回不降。其动机来自既有失败的可能瓶颈，不是瓶颈已被证明。
