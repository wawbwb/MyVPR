# 训练集分支可靠性准入实验V1

目的：先验证是否能从不含标签的检索统计预测“创新点1/原通道哪条分支更可靠”，不直接训练新深度模块，不使用MSLS/Pitts或GSV适配留出查询拟合。

固定使用封存GSV的8192训练地点×4图（32768图）。两分支冻结，原channel取历史seed42最终权重；创新点1复用已验证FP32缓存，原channel补提取同顺序同内容图像描述子。原adapter和创新点1曾在这些地点上训练，所以这只是偏乐观的训练信号检查，不能称为整个模型的未见地点验证。

每地点固定第0视图为查询，其余3图作图库：8192查询、24576图库。GT为同地点3图；其他地点距离查询25m内图库项统一屏蔽以排除近邻假负例。两分支提取FP32精确余弦Top20及分数。该地点标注/GPS过滤仅用于训练数据构建，部署选择器输入不含GPS或地点ID。

查询地点按50m邻近连通分量划组，固定seed42打乱分量，前70%分量为可靠性拟合，其余为留出；同地点及相邻查询不跨组。图库固定，包含全部地点，不对图库描述子再拟合。这是分支选择器的地点留出，不是冻结编码器的地点留出。

14维输入：每分支Top1分数、Top1−Top2/5/20间隔、温度0.05的Top20分数softmax熵（共10维），两分支候选Jaccard、Top1是否一致、彼此Top1在对方Top20的倒数排名（缺席0）。只在拟合集求均值/标准差。

拟合仅使用两分支一对一错的查询，标签1=channel唯一正确、0=创新点1唯一正确；两者同对/同错不提供偏好监督。模型为固定C=1、lbfgs、最多1000次迭代的带截距L2逻辑回归；概率>0.5选channel，否则anchor。选择器在所有留出查询评估，包括训练时不提供偏好标签的同对/同错样本。另拟合固定seed42打乱偏好标签的同容量对照。

拟合集至少30个分歧样本、每类至少10，留出每类至少5，否则报告不足并停止。固定对照：anchor、channel、等权k60 RRF、较大Top1−Top2间隔选择。准入需留出逻辑回归纠错≥5、净增≥3、退化≤纠错的一半，且正确数严格超过RRF、打乱标签、简单间隔和channel。阈值固定，不据结果扫描。未通过不做基准训练/评测扩展；通过也只允许提出后续验证，不能视为论文收益。

只在服务器运行：GPU1补提取及训练检索，显存上限20%并额外留2GB，使用旧排他锁，不影响其他任务；CPU拟合与分析。每64图写可恢复SHA分片，源码、权重来源、输入封存SHA入合同。所有新输出独立，原结果只读。
