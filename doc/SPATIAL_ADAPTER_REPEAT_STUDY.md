# 聚合前空间适配器：多种子复核与纯通道消融

## 固定问题与既有证据

本实验只回答两点：①不依赖CLIP的空间适配器相对官方BoQ的提升，能否在不同随机种子下重复；②提升是否优于近等容量纯通道适配器，从而支持空间交互的额外作用。

旧实验`logs/clip_preboq_v1`于2026-10-18 22:32完成，单种子42：官方/无对抗/真实CLIP/打乱CLIP在Pitts30k-val分别为7264/7269/7270/7270条R@1正确，MSLS均694/740；GSV留出3048/3049/3049/3050。三种适配器共同纠正13条Pitts原模型错误。CLIP变化约束没有表现出可靠额外优势，因此本轮完全移除CLIP、目标、预测器和对抗训练，不继续调对抗权重。

## 网络与配对对照

统一推理：RGB → 冻结官方DINOv2 → 新适配器 → 冻结官方BoQ → 12288维单位全局描述子。仅使用最后一层patch，不融合多层；本实验与创新点1独立。

两组共同：1×1降维768→64，GELU，中间卷积，GELU，1×1升维64→768；残差输出乘0.1加回原特征。末层零初始化，初始描述子必须复现官方。两组升/降维的初始参数完全相同；中间卷积bias及中心权重相同。

|组别|中间卷积|可训练参数|
|---|---|---:|
|spatial|depthwise 3×3，64组|99,776|
|channel|depthwise 1×1，64组|99,264|

channel由spatial的中心核拷贝初始化，中间卷积仅对单个位置处理，前后1×1完成通道混合。它没有新适配器内部的邻域交互；但不意味着冻结DINO和BoQ没有空间建模。两组差512参数，约0.513%，**不是严格等参数**。它是保留其他结构的核尺寸消融，而不是随意去掉整个模块。

## 锁定训练与数据

种子42、43、44，各自从同一官方checkpoint重新开始。固定原seed42计划采样的8192个训练地点×4张图、1024个地点留出×4张图，不重新采样数据。每个种子同时改变适配器初始化与五轮训练顺序；同种子的两组配对初始化及批次顺序一致。旧seed42权重不接续、不覆盖，seed42也重新训练。

固定P16×K4、5轮、每组2560步、FP32、输入322、AdamW lr=3e-4、weight decay=0、梯度裁剪1。损失仅为GPS过滤25米内潜在假负样本后的MS地点检索损失，加0.1×相对官方描述子的余弦保持损失。不按验证集选最佳轮次、种子、学习率或保持权重。

每个种子成对训练，两组共享同一次冻结DINO和官方描述子计算，但适配器参数、优化器、反向梯度完全分离；无跨图像模块或两组间知识共享。沿用分块梯度重算，控制显存；原始稠密特征只在当前批次内存中保留，不写磁盘。

先服务器CPU测试，再seed42双组各8步机械smoke，全部通过后丢弃smoke参数并重新正式初始化。每16步原子保存两组参数、两个优化器、步数及RNG，可以相同契约恢复。只用物理GPU1，单进程显存上限20%；不清理其他进程、不回退GPU0。

## 评测、汇总与解释

每个种子训练完成后评测GSV地点留出、MSLS-val、Pitts30k-val，保留Top20、逐查询纠错/退化。**预先指定Pitts30k-val为主要开发端点**，因既有收益集中在该数据集；同时完整报告另两个数据集，不能只报告最好一个。没有新盲测集，也不能把开发集复用说成确认性验证。

三个种子全部完成后，逐数据集汇总spatial−official、channel−official、spatial−channel的各种子差值、均值、样本标准差、最小/最大值、正/平/负种子数及是否三种子全正。相同查询被多次评测，不将其拼成3倍独立样本。跨种子必须使用相同图像内容、顺序、GT和官方基线预测。

若空间组反复优于官方但不优于通道组，支持“额外轻量适配容量”的解释，而不能归因于邻域卷积。若空间组反复优于两者，支持在当前训练协议下的空间交互增益，但不直接证明相对所有论文的新颖性或跨数据集稳定泛化。三个种子仍是小规模复核。

本次不会据早期种子结果提前换方案或自动增加实验。创新点1、专利初稿、旧CLIP实验和官方checkpoint均只读；旧封存源文件不改动。
